# 🎮 GameVault

Marketplace para compra e venda de contas de jogos e creditos.

## Funcionalidades

- 🛒 Loja de contas de jogos (Free Fire, COD Mobile, Roblox, etc.)
- 💎 Loja de creditos (Diamantes, CP, Robux, UC, etc.)
- 👤 Sistema de usuarios (vendedores e compradores)
- 🔐 Painel admin completo
- 💰 Pagamentos via PIX e Criptomoeda
- 🤖 Integracao com Telegram
- 📊 Dashboard com graficos

## Stack Tecnologica

- HTML5, CSS3, JavaScript
- PHP 7.4+
- MySQL 8.0
- Design Cyberpunk/Neon

## Instalacao

1. Clonar o repositorio
2. Importar `sql/schema.sql` no MySQL
3. Configurar `config.php` com credenciais do banco
4. Acessar via navegador
